## PR description cleanup

The .claude/settings.json attribution setting is not reliably honored for
PR descriptions (confirmed: Claude Code adds a "🤖 Generated with Claude
Code" footer, a Claude-Session: link, and/or a "Generated by Claude Code"
line to PR bodies regardless of that setting — this is a known upstream
bug, not a repo misconfiguration).

After opening a PR with `gh pr create`, always follow up with `gh pr edit
<number> --body "..."` to strip any line containing any of: "Claude
Code", "claude.ai/code", "Generated with", "Generated by", "Co-Authored-
By: Claude", "Claude-Session:". Do this as a required last step of every
PR you open in this repo, not just when explicitly asked.

Fetch the current body first (gh pr view <number> --json body -q .body),
filter out matching lines, trim any resulting trailing blank lines, then
write the result back. Don't touch any other content in the description.

Verify: after creating this file, open a trivial test PR (or use the
next real one) and confirm its body has none of the above after your
cleanup step runs.
